# Portfolio v2

## About
This repository contains the second version of my personal portfolio website. It highlights my professional journey as a Senior Cybersecurity Engineer, showcasing my skills, achievements, and projects in a modern, responsive design. The portfolio serves as a digital résumé and personal brand hub.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Design:** Responsive layout, dark/light mode toggle
- **Hosting:** GitHub Pages (planned)
- **Version Control:** Git & GitHub

## Features
- Professional summary and About Me section
- Work Experience with detailed achievements
- Skills section with iconography and improved alignment
- Projects showcase
- Contact information and action buttons
- Dark/light mode toggle for accessibility
- SEO enhancements and typography improvements
